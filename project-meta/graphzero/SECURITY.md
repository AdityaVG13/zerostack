# Security Policy

## Reporting a vulnerability

Use GitHub Security Advisories for private reporting:

- Go to **Security → Report a vulnerability** on https://github.com/AdityaVG13/graphzero
- Or open `https://github.com/AdityaVG13/graphzero/security/advisories/new`

Do not open a public GitHub Issue for a suspected vulnerability.

Include a description, impact, reproduction steps or proof of concept, and any affected versions or commits if known. The maintainer will acknowledge receipt and follow up via the advisory.

## Scope

This policy covers the GraphZero repository at `AdityaVG13/graphzero`. Adjacent engines (FSZero, TokenZero) and the ZeroStack hub have their own repositories and policies.
