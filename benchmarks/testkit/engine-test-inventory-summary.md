## Static-discovery limitations

- Inline cfg(test) modules are included because all eligible Rust sources are parsed.
- Statically named proptest functions retain exact names. A block with no visible function gets one stable proptest_macro_case_L<line> row.
- Other macro-generated harness names require expansion. No names are fabricated, so historical harness totals need not match.
- Parsing is deliberately conservative; commented or dynamically generated cases are not executable tests.
