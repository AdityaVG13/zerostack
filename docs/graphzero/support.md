# Support

For questions, bug reports, and feature requests, use GitHub Issues:

- https://github.com/AdityaVG13/graphzero/issues

Include GraphZero version, Rust toolchain (`rustc --version`), OS, reproduction steps, and relevant logs. For sensitive security matters, use the private channel in `SECURITY.md` instead of a public issue.

Documentation entry points:

- `README.md` — install, quick start, CLI and MCP reference
- `docs/README.md` — documentation index
- `docs/architecture.md` — technical design and crate map
- `docs/benchmarks.md` — gates and how to run them
