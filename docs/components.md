# Components

## TokenZero

[TokenZero](https://github.com/AdityaVG13/tokenzero) is the public context-compression engine. It compacts and deduplicates bulky outputs, returns recoverable `tz://` refs, and supports selective expansion when exact evidence is needed.

**Status:** public. Use its repository for source, releases, issues, and installation instructions.

## FSZero

FSZero is the live-filesystem engine. It provides focused reads and search, higher-level filesystem plans, and controlled mutation workflows while returning recoverable `fz://` refs.

**Status:** private and in development. No public source or installation instructions are available yet.

## GraphZero

GraphZero is the structural code-intelligence engine. It provides repository orientation, symbol relationships, dependency and impact analysis, and graph-backed recall through `gz://` refs.

**Status:** private and in development. No public source or installation instructions are available yet.

## Together

TokenZero controls context cost. FSZero supplies exact live state. GraphZero supplies structure. RACC lets their outputs cross engine boundaries as small recoverable handles, while CodeMode can batch the complete workflow in a single execution.
