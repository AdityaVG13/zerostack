# Components

## TokenZero

[TokenZero](https://github.com/AdityaVG13/tokenzero) compacts and deduplicates bulky outputs, returns recoverable `tz://` refs, and supports selective expansion when exact evidence is needed.

## FSZero

FSZero is the live-filesystem engine: focused reads and search, higher-level filesystem plans, and controlled mutation. Results come back as recoverable `fz://` refs.

## GraphZero

GraphZero is the structural engine: repository orientation, symbol relationships, dependency and impact analysis, and graph-backed recall through `gz://` refs.

## Together

TokenZero controls context cost. FSZero supplies live state. GraphZero supplies structure. RACC lets their outputs cross engine boundaries as small recoverable handles. CodeMode can run the whole sequence in one plan.
