\section{Dominance-Complete Recovery}
\textbf{Conditional theorem target.} The systems premises must be explicit in the matching Lean declaration.
\begin{theorem}[Dominance-Complete Recovery]
A deterministic protocol can select one pointwise baseline-dominant accessible effect from a history if and only if the intersection of accessible effects that dominate the baseline over every world consistent with that history is nonempty.
\end{theorem}

\begin{theorem}[Guarded baseline dominance]
