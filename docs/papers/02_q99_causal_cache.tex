\section{Component savings dilution}
\textbf{Conditional theorem target.} The denominator and systems premises must be explicit in the matching Lean declaration.
\begin{theorem}[Component savings dilution]
If baseline work is $W_B=\sum_i W_i$, component $i$ is reduced by $r_i$, and overhead is $H$, then total savings equal
\[
\sum_i \frac{W_i}{W_B}r_i-\frac{H}{W_B}.
\]
\end{theorem}
